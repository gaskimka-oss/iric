**259 команд в 33 разделах**: модерация с рангами, экономика, игры,
ИИ-надзор, админ-панель. Все данные — в своей SQLite-базе.

## 🚀 Запуск

```bash
pip install -r requirements.txt
python bot.py
```

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от [@BotFather](https://t.me/BotFather) — обязательно |
| `OWNER_ID` | ваш Telegram ID (есть значение по умолчанию) |
| `DATA_DIR` | папка базы (бот сам найдёт постоянную) |
| `AI_API_KEY` | ключ нейросети для ИИ-надзора — необязательно |
| `AI_API_URL` | адрес API, если не OpenAI — бот угадает по ключу |
| `AI_MODEL` | модель, если нужна конкретная |

- ✉️ Рассылка напоминаний тем, кто без анкеты

## 🤖 Автомодерация

`автомут вкл` — мут за оскорбления и мат в адрес человека.

Мат-междометия **не наказываются**: «бля», «пиздец», «заебался»,
«нахуй эту работу» проходят спокойно. Наказывается только адресное:
«ты пидор», «иди нахуй», «он мудак».

| Команда | Действие |
|---|---|
| `автомут тест фраза` | проверить без наказания |
| `автомут время 2 часа` | срок мута |
| `автомут строгий вкл` | наказывать любой мат |
| `нарушения` | журнал срабатываний |

Словарь на 271 корень ловит обходы: `дeбил`, `д е б и л`, `DEBIL`, `ty debil`.

## ⚖️ Наказания

Мут, бан, варн и кик **требуют причину**, мут и бан — ещё и срок.
Уведомления удаляются автоматически через 3 минуты.

```
мут @user 2 часа спам
бан @user 7 дней нарушение п.3
варн @user оскорбление
```

Списки: `мутлист` · `банлист` · `варнлист` · `преды` (свои) ·
`история @user` (ранг 6+)

## 🔐 ДК и ЛДК

**ДК** — какой ранг нужен для каждой команды:
`ДК бан 3` · `ДК казино выкл` · `+ДК 16` (раздел целиком) · `ДК 4` (что доступно рангу)

**ЛДК** — персональные права поверх рангов:
`+лдк @user мут` — выдать · `-лдк @user бан` — забрать

## 💊 Граммы и игры

Вторая валюта с играми: `орёл` · `мины` · `дартс` · `краш` · `колесо` ·
`сапёр` · `рулетка`

`б` — баланс · `бонус граммы` — 100 000 в сутки · `обмен 200` — граммы в ириски
(20:1) · `выпка` — VIP за 100 000 ирисок

**Выдача выпки админом** (ранг 4+):

| Команда | Что делает |
|---|---|
| `выдать выпку @ник 7 дней` | выдать бесплатно, срок любой |
| `выдать выпку @ник навсегда` | бессрочно |
| `снять выпку @ник` | забрать досрочно |
| `кто с выпкой` | список всех, у кого есть |

Если выпка уже есть — срок продлевается.

Привязка к теме: `тема граммов` (или `тема граммы`, `тема казино`)

## 📝 Обязательные анкеты

`тема описания` — новички не смогут писать, пока не заполнят описание.
Разрешена только назначенная тема, в остальных сообщения удаляются.

Пока описания нет, человек не может слать **голосовые, кружочки, фото,
видео, стикеры и файлы**. Заполнившим вход в тему анкет закрывается.

Бот принимает анкету **в любом оформлении** — по шаблону с двоеточиями,
с эмодзи в начале строк или просто свободным рассказом о себе.

| Команда | Что делает |
|---|---|
| `шаблон` | форма анкеты одним сообщением |
| `+описание` | добавить или изменить своё |
| `описание @ник` | посмотреть чужое |
| `изменить описание @ник` | вписать человеку свой текст (ранг 4+) |
| `изменить описание @ник сброс` | вернуть обычную анкету |

Все служебные подсказки бота самоудаляются, чтобы не сорить в теме.

## 🧠 ИИ-надзор

Проверяет каждое наказание и следит за чатом с учётом контекста.

| Команда | Что делает |
|---|---|
| `ии` | статус, сервис, статистика (ранг 6+) |
| `ии сводка` | обстановка в чате |
| `ии проверь текст` | оценить фразу |
| `ии оповещения выкл` | не писать в ЛС о спорных |

Если модератор наказал несправедливо, ИИ пишет владельцу в личку
с разбором и советом. Отличает дружеский подкол от оскорбления
и мат «в воздух» от адресного.

Работает через любой OpenAI-совместимый сервис. Достаточно задать
`AI_API_KEY` — остальное бот определит сам. Без ключа работает
словарь на 271 корень.

## ✨ Префиксы

Каждая команда работает в пяти вариантах:

```
!бан   .бан   /бан   Ирис бан   бан
```

Фильтр строгий: «банан» и «забанил» бота не разбудят.

## 🩺 Если что-то не так

| Симптом | Причина |
|---|---|
| Команды без слэша не работают | Privacy Mode — отключите в @BotFather и перезайдите в чат |
| «Недостаточно прав» | нужен ранг выше — проверьте `мой ранг` |
| Мут не проходит | цель — админ Telegram, ботам их трогать нельзя |
| База пустеет после рестарта | не подключён volume к `/app/data` |
| `TelegramConflictError` | запущены две копии бота |
