# 🤖 Iris-подобный чат-менеджер для Telegram

Полностью ваш бот: **124 команды в 30 разделах**, система рангов, модерация,
экономика, игры и десятки модулей. Все данные — в вашей SQLite-базе.

📖 **Живая справка:** https://telegra.ph/Komandy-bota-07-26

---

## ⚠️ Про токен

Токен, который засветился в переписке, считается скомпрометированным.
@BotFather → `/mybots` → бот → **API Token** → **Revoke current token**,
новый впишите в `.env` (файл в `.gitignore`, в репозиторий не попадёт).

## 👑 Защита Лидера клана

**7 ранг неприкосновенен.** Его нельзя забанить, замутить, кикнуть, предупредить,
понизить или снять — даже владельцу бота. Команда `!снять всех` тоже его не трогает.
Через `-ЛДК` у него нельзя отобрать команды.

Всем остальным (0–6) наказания выдаются как обычно, с учётом иерархии:
нельзя тронуть равного или старшего по рангу.

---

## ⚖️ Наказания только с причиной

Мут, бан, варн и кик **требуют причину**, а мут и бан — ещё и срок.
Если модератор забыл, бот подсказывает формат:

```
❗️ Нельзя выдать мут без причины.

Правильный формат:
мут @юзер {время} {причина}

Примеры:
мут @user 2 часа спам
мут @user 7 дней нарушение п.3 правил
```

Для бессрочного бана добавьте слово `навсегда`.
Отключить требование: `причина обязательна выкл` (ранг 4+).

### Списки и история

| Команда | Что показывает |
|---|---|
| `мутлист` | активные муты: кто, срок, причина, кем выдан |
| `банлист` | активные баны с причинами |
| `варнлист` | активные предупреждения |
| `история @user` | полное досье — все наказания (ранг 6+) |
| `наказание 42` | детали по номеру (ранг 6+) |
| `статистика модерации` | кто сколько наказаний выдал (ранг 4+) |

Каждое наказание получает номер `#42` и пишется в журнал: тип, причина, срок,
кто выдал, когда, снято или активно.

## 🔓 Открытие и закрытие чата

| Команда | Действие |
|---|---|
| `+чат` | открыть чат прямо сейчас |
| `-чат` | закрыть (писать могут только админы) |
| `+чат 08:00` | автоматически открывать каждый день в 8:00 |
| `-чат 23:00` | автоматически закрывать каждый день в 23:00 |
| `+чат меню` | выбрать время кнопками |
| `расписание чата` | показать текущее расписание |
| `часовой пояс 3` | часовой пояс (по умолчанию МСК) |
| `+чат авто выкл` | отключить автоматику |

Бот сам открывает и закрывает чат по расписанию и пишет об этом в группу.

## 🔑 ЛДК — Личный доступ команд

Персональные права поверх рангов: можно **выдать** команду человеку без нужного
ранга или **отобрать** у того, у кого ранг есть.

| Команда | Действие |
|---|---|
| `+лдк @user мут` | выдать доступ к команде лично |
| `-лдк @user бан` | забрать команду у человека |
| `лдк @user` | что выдано и что отобрано |
| `лдк` | все личные настройки чата |

Работает реплаем и по id. У Лидера клана отобрать ничего нельзя.

---

## 🔐 ДК — Доступ команд

Гибкая настройка: какой ранг нужен для каждой из 127 команд.

| Команда | Действие |
|---|---|
| `ДК` | меню с кнопками по разделам |
| `ДК бан 3` | «бан» доступен с 3 ранга |
| `ДК бан 0` | разрешить всем участникам |
| `ДК казино выкл` | отключить команду в чате |
| `ДК казино вкл` | включить обратно |
| `ДК бан` | показать текущий доступ |
| `ДК мут 2` | мут только со 2 ранга — у 1 ранга прав не будет |
| `ДК список` | все изменённые команды |
| `ДК тихо вкл` | не писать отказы о нехватке прав |
| `ДК сброс` | вернуть настройки по умолчанию |
| `лог ДК` | история изменений |

Через меню `ДК` всё то же самое делается кнопками: раздел → команда → ранг 0–7.
Нельзя выставить команде ранг выше собственного.

**Ранг 0 = обычные участники.** Так можно выдать команду вообще всем:
`ДК бан 0`. По умолчанию 73 безвредные команды (игры, экономика, профиль)
уже доступны игрокам, а опасные (мут, бан, чистка) — только модерации.

## 👥 Настройка для групп

### 1. Отключите Privacy Mode — обязательно
@BotFather → `/mybots` → бот → **Bot Settings** → **Group Privacy** → **Turn off**

Без этого бот видит только команды со слэшем: не работают команды без префикса,
триггеры и счётчик активности.

> Если бот **уже** в группе — удалите его из чата и добавьте заново,
> иначе настройка не применится.

### 2. Дайте права администратора
При добавлении бот **сам пришлёт кнопку** «⚙️ Выдать права администратора» —
Telegram откроет диалог с уже отмеченными галочками:

🔧 Управление группой · 🗑 Удаление сообщений · 🚫 Блокировка пользователей
📌 Закрепление сообщений · 🔗 Приглашение по ссылке

Бот отследит выдачу и сообщит, чего не хватает. Рядом кнопка «🩺 Проверить права».

> 👑 **Владелец группы автоматически получает 7 ранг** (Лидер клана)
> при первом входе бота — настраивать ничего не нужно.

### 3. Проверьте
Напишите в чате `проверка` — бот выдаст чеклист и подскажет, чего не хватает.

## ✨ Префиксы — как в Ирисе

Любая команда работает в пяти вариантах:

```
!бан        .бан        /бан        Ирис бан        Ириска бан        бан
```

Фильтр строгий: «банан», «забанил», «этот бан» бота не разбудят.

## 📖 Меню команд с кнопками

Команда **`команды`** открывает интерактивное меню:

- 30 кнопок-разделов с постраничной навигацией
- клик по разделу → список команд **прямо в чате** + смена картинки
- кнопка **«🔗 Открыть этот раздел в справке»** → ссылка на telegra.ph
  с якорем именно на нужный раздел
- кнопка **«🌐 Вся справка одной страницей»**
- поиск: `найти бан` — покажет все совпадения и даст ссылку

Справка публикуется автоматически при старте и всегда соответствует коду:
и меню, и веб-страница строятся из одного реестра команд.

## 🎖 Система рангов (0–8)

| Ранг | Звёзды | Название | Примеры доступа |
|---|---|---|---|
| 0 | — | Участник | игры, экономика, анкета |
| 1 | ⭐ | Младший модератор | мут, кик, варн, удаление, созыв |
| 2 | ⭐⭐ | Старший модератор | бан, чистка, теги, розыгрыши, триггеры |
| 3 | ⭐⭐⭐ | Младший админ | правила, приветствие, награды, лимит варнов |
| 4 | ⭐⭐⭐⭐ | Старший админ | доступ команд, автокик, антиспам, сетка |
| 5 | ⭐⭐⭐⭐⭐ | Создатель | снять всех, сброс настроек, импорт состава |
| 6 | ⭐⭐⭐⭐⭐⭐ | Технический администратор | настройки бота, история наказаний |
| 7 | ⭐⭐⭐⭐⭐⭐⭐ | Заместитель лидера | почти все права, кроме смены лидера |
| 8 | ⭐⭐⭐⭐⭐⭐⭐⭐ | Лидер клана | высший ранг, неприкосновенен |

`OWNER_ID` всегда имеет ранг 8. Создатель чата в Telegram → 5, админ → 3.
Поддерживаются **анонимные админы** (сообщения от имени группы).

Выдать ранг можно только **ниже своего** — иерархия защищена.

### Команды рангов

| Команда | Действие |
|---|---|
| `+модер @user` | 1 ранг (можно `+модер 8 @user`, работает и `!!!!модер`) |
| `повысить @user` | +1 ранг · `повысить 6 @user` — сразу до 6 |
| `понизить @user` | −1 ранг (синоним `разжаловать`) |
| `снять @user` | полностью снять ранг |
| `снять вышедших` | убрать покинувших чат |
| `!снять всех` | снять ранги со всех (ранг 5+) |
| `ранги` | таблица всех рангов и привилегий |
| `мой ранг` | свой ранг (или чужой — реплаем) |

### Состав модерации

Команды **`кто админ`**, `кто модеры`, `состав`, `стафф`, `модераторы` показывают
список в фирменном формате:

```
👮 Состав модерации

⭐⭐⭐⭐⭐ Создатели
🏐 Simba
🏐 Фанат
🏐 ZRG_Oblivion
➖ Натали

⭐⭐⭐⭐ Старшие админы
🏐 D乇尺ZKaㄚa
🏐 Kaktys6390
🏐 Филипп
```

`🏐` — в чате, `➖` — вышел. Имена кликабельны, порядок сохраняется.
`кто создатель` покажет только руководство (ранг 5+).

### Импорт готового списка

Отправьте список в чат и ответьте на него командой **`импорт состава`** —
бот распознает звёзды, названия рангов, markdown-ссылки, @ники и метку `➖`.
Шаблон лежит в `staff_example.txt`.

Вручную: `добавить в состав 4 @user Филипп` · `удалить из состава @user`

## 🖥 Круглосуточная работа (VPS)

```bash
sudo tee /etc/systemd/system/irisbot.service <<'EOF'
[Unit]
Description=Iris-like Telegram bot
After=network.target

[Service]
Type=simple
WorkingDirectory=/root/irisbot
ExecStart=/usr/bin/python3 /root/irisbot/bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload && sudo systemctl enable --now irisbot
journalctl -u irisbot -f
```

Бэкап — скопируйте `data/iris.db`.

## 🩺 Если что-то не так

| Симптом | Причина |
|---|---|
| Команды без слэша не работают | включён Privacy Mode — отключите и перезайдите в чат |
| «Недостаточно прав» | нужен ранг выше — см. `мой ранг` |
| Мут/бан не проходят | бот не админ или у цели выше права |
| `Unauthorized` при старте | токен отозван — возьмите новый |
| Картинки не приходят | проверьте папку `assets/` рядом с `bot.py` |
